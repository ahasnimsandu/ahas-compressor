AHAS 2.0 — Apple Silicon Edition
Made by Ahas Nimsandu

INSTALL
Drag AHAS.app to Applications, eject this disk image, then open AHAS.
The app bundles Python. No Python/pip/Node installation or account is needed.

CHOOSE YOUR MODE
LOSSLESS ARCHIVE creates .ahas v2 files using solid XZ/LZMA2, duplicate-file
removal, and zero-run elision. Exact supported regular-file bytes can be
restored. Legacy .cla archives can still be extracted/verified.

MEDIA OPTIMIZER is a separate, explicitly LOSSY mode. It can lower image/video
quality and resolution, change metadata/color/HDR/tracks, and remove
transparency or animation. Accept the consent box first. Originals stay
untouched; failed or larger conversions are copied unchanged into the new
output folder instead. Uses macOS sips/avconvert; codec support varies.

SAFETY
Save archives/output folders outside source folders. Existing destinations
are never overwritten. Verify and test extraction before deleting originals.
The archive does NOT preserve resource forks, extended attributes, Finder
tags, ACLs, owners, creation dates, or hard-link identity. Symbolic links and
special files are skipped/reported. No encryption. Not a full backup tool.
No universal 50 GB -> 50 MB ratio is possible for arbitrary files.

Quit with Command-Q or close the window. An active job is cancelled only
after confirmation and cleanup. Logs: ~/Library/Logs/AHAS/app.log

BUILD STATUS
Apple Silicon arm64, macOS 11+ build target. This development artifact was
cross-built on Linux and has not been executed or mounted on a real Mac here.
Ad-hoc signatures only: NOT Developer ID signed and NOT Apple notarized.
Native startup, media conversions, minimum-OS compatibility, and Gatekeeper
behavior still require actual Mac testing.

If macOS blocks the download, do not disable Gatekeeper globally or assume a
"damaged" warning is harmless. Check checksums/signatures and use the included
native-macOS build workflow before relying on a public release.
